“the hot wells” ≠ “hot springs”

The participants share a task, not a view. GMMT records what each participant takes a referring expression to mean; SINS asks whether a model can tell when those interpretations diverge.

Abstract

Collaborative dialogue is often analysed as if each referring expression had one agreed referent. MapTask makes that assumption testable: a route giver and follower work from similar but non-identical maps, so the same words can resolve to different landmarks for each participant.

GMMT introduces a perspectivist annotation scheme that separately records the giver's intended landmark and the follower's interpreted landmark for every reference expression. SINS builds a controlled common-ground judgment task on those paired interpretations and evaluates whether vision–language models distinguish what participants could share from what they have actually established in dialogue.

Research question
Can a model see both maps without mistaking visual availability for shared understanding?

Main result

Seeing more does not guarantee understanding more

Access to authentic maps improves overall macro-F1 for Qwen3-VL-8B under the primary startT setting. Yet it also shifts predictions toward agreement: the model often treats visually available common ground as if participants had already established it in dialogue.

  • GMMT exposes disagreement that a single-reference annotation would erase.
  • SINS separates dialogue evidence from access to one or both maps.
  • The map condition raises the model's predicted “Yes” rate by 21.2 points.
